## Risks and Open Questions

1. **Merge strategy:** If main has diverged from the feature branch base, a merge commit (not fast-forward) will be created. This is fine — the feature branch is a direct descendant of main's ancestry.

2. **Test runtime:** The full suite is slow on this box due to chDB cold-start. If it times out, use background execution. Do not skip the full suite — the point is to verify the analytics fixes don't break existing tests.

3. **chDB data path collision:** Use a fresh `CHDB_DATA_PATH` for the merged test run to avoid any residual state from previous test runs.

4. **README checklist item:** The PR checklist still has "README analytics section updated (follow-up)" unchecked. This is NOT blocking the merge — it's a follow-up task.
